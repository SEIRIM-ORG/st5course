### Goals

In this section we cover unapproved applications, personal devices, browser extensions, macros, scripts, unknown USB devices, Shadow IT, and why free software downloaded from untrusted websites can quietly become company data exposure.

Overall the guidance is to install software only from trusted or official sources, keep devices protected, and avoid unmanaged tools that bypass company controls. Key advice is downloading updates from trusted vendor websites or trusted app stores.

### Learning Objective

By the end of this section, we will understand why company work should be done only on approved devices, approved software, and approved services.

Employees should learn this core behavior:

**Do company work only on approved devices and approved tools. Do not install, connect, or use unapproved software for company information.**

Managers and executives should learn this assurance principle:

**The company must know which devices and software are used for work, and must be able to manage, update, protect, and remove them when needed.**

### Why This Matters

Every device or software tool used for company work can become a doorway into company data.

**Unapproved devices and software may not have:**

- Security updates
    
- Antivirus or endpoint protection
    
- Company monitoring
    
- MFA controls
    
- Data backup
    
- Encryption
    
- Access logging
    
- Company support
    
- Proper configuration
    
- Vendor review
    
- Removal or offboarding controls
    

**This matters because employees often use unapproved tools for convenience:**

- A personal laptop
    
- A personal phone
    
- A free online converter
    
- A personal cloud drive
    
- A browser extension
    
- A personal messaging app
    
- A free remote-access tool
    
- An unapproved AI tool
    
- A USB drive
    
- A software trial
    
- A personal email account
    

The intention may be productivity, but the result can be data exposure, malware, loss of visibility, or uncontrolled access.

### Core Rule

Use only company-approved devices, software, apps, cloud tools, and services for company work.

**If a tool is not approved, do not use it to:**

- Store company files
    
- Transfer company data
    
- Process customer information
    
- Access company systems
    
- Connect to work email
    
- Record meetings
    
- Convert documents
    
- Summarize files
    
- Share credentials
    
- Analyze spreadsheets
    
- Handle confidential information
    

The safest question is:

**Would IT, security, or leadership know this device or tool is being used for company data?**

If the answer is no, stop and ask.

### Approved Devices

**Approved devices may include:**

- Company laptops
    
- Company desktops
    
- Company phones
    
- Company tablets
    
- Managed personal devices, if allowed by policy
    
- Approved remote-work devices
    
- Approved point-of-sale or operational devices
    

An approved device is one the company can manage, update, secure, and remove access from when needed.

Employees should avoid using unmanaged personal devices for company work unless company policy specifically allows it.

### Approved Software

**Approved software may include:**

- Company email
    
- Company cloud storage
    
- Approved browsers
    
- Approved office applications
    
- Approved communication tools
    
- Approved file-transfer tools
    
- Approved PDF tools
    
- Approved password manager
    
- Approved security software
    
- Approved AI tools
    
- Approved business applications
    
- Approved mobile apps
    

Employees should install software only from approved company channels, official vendor websites, or trusted app stores, depending on company policy.

### Common Unsafe Shortcuts

Employees should avoid these common shortcuts:

#### 1. Personal Devices

Using a personal laptop or phone for work may expose company data if the device is not secured, updated, encrypted, or monitored.

**Correct behavior:**

Use company-approved devices or follow the company’s bring-your-own-device policy.

#### 2. Free Online Tools

Free tools for PDF conversion, image compression, file transfer, translation, or document editing may store uploaded files.

**Correct behavior:**

Use approved company tools.

#### 3. Unapproved Browser Extensions

Browser extensions can sometimes read page content, track activity, or access data in web applications.

**Correct behavior:**

Install only approved extensions.

#### 4. Personal Cloud Storage

Personal storage accounts may not have company controls, retention policies, or access removal.

**Correct behavior:**

Use company-approved cloud storage.

#### 5. Unknown USB Devices

USB devices can carry malware or expose data.

**Correct behavior:**

Use only approved removable media, if allowed.

#### 6. Unapproved Remote-Access Tools

Remote-access software can allow outsiders into company systems.

**Correct behavior:**

Use only company-approved remote access.

#### 7. Unapproved AI Tools

AI tools can receive prompts, files, transcripts, code, and confidential data.

**Correct behavior:**

Use only approved AI tools and follow data rules.

### What Employees Should Do

**Employees should:**

1. Use approved company devices for work.
    
2. Use approved software and services.
    
3. Install apps only through approved sources.
    
4. Ask before installing browser extensions.
    
5. Avoid personal cloud storage for company files.
    
6. Avoid personal email for company work.
    
7. Use approved AI tools only within company rules.
    
8. Report lost, stolen, or unmanaged work devices immediately.
    
9. Report unknown or suspicious software.
    
10. Ask IT before using a new tool with company data.
    

### What Employees Should Not Do

**Employees should not:**

- Install random software from the internet
    
- Use personal devices for work without approval
    
- Upload company files to free online tools
    
- Use personal email to move company documents
    
- Connect unapproved apps to company accounts
    
- Install unapproved browser extensions
    
- Use unknown USB drives
    
- Disable company security tools
    
- Use unapproved remote-access software
    
- Store work files in personal cloud accounts
    
- Use unapproved AI tools with company information
    

### Fake Software and Download Warning

Attackers often disguise malware as useful software.

**Be cautious with:**

- “Urgent update” pop-ups
    
- Free versions of paid software
    
- Cracked or pirated software
    
- Unknown download links
    
- Browser extensions with broad permissions
    
- Tools promoted through suspicious ads
    
- Installers sent by email
    
- Fake meeting, PDF, or video-player updates
    

**Correct action:**

**Do not install it. Use official company software channels or ask IT.**

### Manager Responsibilities

Managers should not create pressure that pushes staff into unsafe tools.

**Managers should:**

- Make sure teams know which tools are approved
    
- Avoid asking staff to use personal accounts or devices
    
- Escalate tool needs instead of allowing workarounds
    
- Ensure contractors use approved collaboration methods
    
- Report repeated requests for unapproved tools
    
- Support employees who pause before using questionable software
    
- Make sure new staff are set up with the right tools quickly
    

If employees need unapproved tools to get work done, that is a process problem leadership should fix.

### Executive and Key Staff Assurance Points

Executives and key staff should verify that the company can identify and manage the devices and software used for work.

**Leadership should ensure the company has:**

- Device inventory
    
- Software inventory
    
- Approved application list
    
- Approved AI tool list
    
- Rules for personal devices
    
- Rules for browser extensions
    
- Rules for USB and removable media
    
- Rules for remote access
    
- Vendor/security review for new tools
    
- A process for requesting software
    
- A process for removing access when staff leave
    
- Monitoring for unsupported or unapproved software where practical
    

The leadership question is:

**Do we know what devices and tools are handling company data, and can we control them?**

### Questions Leaders Should Ask

**Executives and key staff should ask:**

1. Do we have a current device inventory?
    
2. Do we have a current software inventory?
    
3. Which tools are approved for company data?
    
4. Which AI tools are approved?
    
5. Are personal devices allowed, and under what conditions?
    
6. Are employees using personal cloud storage or personal email?
    
7. Are browser extensions controlled?
    
8. Are unsupported applications identified?
    
9. Are contractors using approved tools?
    
10. Can we remove access when someone leaves?
    

### Key Takeaway

Unapproved devices and software create hidden risk.

Employees should use only approved devices, software, cloud tools, browser extensions, remote-access tools, and AI services for company work. Managers should prevent unsafe workarounds. Executives should verify that the company has device inventory, software inventory, approved tool lists, and a process for controlling unsupported or unapproved tools.

**If the company cannot see or manage the tool, it cannot reliably protect the data inside it.**
