### Install Updates and Restart Promptly



### Short Scenario

An employee receives a restart prompt after a security update but keeps postponing it for two weeks because they do not want to interrupt their work.

**Ask learners:**

1. What is risky about this?
    
2. Why might the restart matter?
    
3. What should the employee do?
    
4. What should the manager support?
    

Expected answer:

The update may not be fully applied until restart. The employee should restart promptly at a suitable time, and the manager should support short downtime for security updates.

### Short Knowledge Check

**Question 1:** Why are software updates important?

A. They only change the appearance of apps  
B. They can fix security flaws attackers may exploit  
C. They are optional for work devices  
D. They remove the need for MFA

**Correct answer:** B

**Question 2:** Why should restart prompts not be ignored indefinitely?

A. Restarts may be needed to finish applying security updates  
B. Restarts only improve screen brightness  
C. Restarting deletes all files  
D. Restarting is never required

**Correct answer:** A

**Question 3:** What should you do if an update prompt appears from an unfamiliar website?

A. Install it immediately  
B. Ignore company policy  
C. Stop and check through official settings or IT  
D. Send it to coworkers

**Correct answer:** C

**Question 4:** What should leadership verify?

A. Whether employees like updates  
B. Whether patching is tracked, reported, and completed on time  
C. Whether unsupported devices are kept forever  
D. Whether updates are always delayed

**Correct answer:** B

### Use Only Approved devices and Software



### Evidence Leaders Should Request

Useful evidence includes:

- Device inventory
    
- Software inventory
    
- Approved application list
    
- Approved AI tool list
    
- Browser extension report
    
- Personal device policy
    
- Remote access policy
    
- Unsupported software list
    
- Software request workflow
    
- Endpoint protection coverage report
    
- Offboarding checklist
    
- Shadow IT or unapproved tool findings
    

### Short Knowledge Check

**Question 1:** Why should employees use only approved software?

A. Approved software is always cheaper  
B. The company can manage, update, secure, and support it  
C. Unapproved software is always illegal  
D. Approved software never has bugs

**Correct answer:** B

**Question 2:** What should you do before using a new tool with company data?

A. Try it first and decide later  
B. Check whether it is approved  
C. Use a personal account  
D. Upload a small sensitive file to test it

**Correct answer:** B

**Question 3:** Which is a risky behavior?

A. Using the approved company cloud storage  
B. Installing an unapproved browser extension that can read website data  
C. Asking IT for an approved PDF tool  
D. Reporting a lost work device

**Correct answer:** B

**Question 4:** What should leadership verify?

A. Whether devices and software used for work are inventoried, approved, and managed  
B. Whether employees can install any app they like  
C. Whether personal storage is easier  
D. Whether unsupported tools are popular

**Correct answer:** A

A. Leave it open if you are coming back soon  
B. Lock the screen

B. Using a privacy screen in public

**Correct answer:** A

### Vulnerability Scanning and Management


### Short Knowledge Check

**Question 1:** What is the goal of vulnerability scanning?

A. To create long reports only  
B. To identify weaknesses before attackers exploit them  
C. To replace employee training  
D. To slow down the business

**Correct answer:** B

**Question 2:** What is the real result of vulnerability management?

A. A scan report  
B. A meeting about findings  
C. A fixed, mitigated, or accepted vulnerability with ownership and evidence  
D. A list no one reads

**Correct answer:** C

**Question 3:** Which vulnerability should usually be prioritized?

A. A low-risk issue on an unused system  
B. A known exploited issue on an internet-facing system  
C. A cosmetic issue in a document template  
D. A fixed issue from last year

**Correct answer:** B

**Question 4:** What should leadership verify?

A. Whether vulnerabilities are found, prioritized, owned, remediated, and verified  
B. Whether scan reports are ignored  
C. Whether employees can disable security tools  
D. Whether unsupported systems are kept indefinitely

**Correct answer:** A

### Systems Hardening and Protective Controls



### Short Knowledge Check

**Question 1:** What is system hardening?

A. Making systems harder for employees to use for no reason  
B. Configuring systems to reduce unnecessary security risk  
C. Buying new computers every year  
D. Turning off all software updates

**Correct answer:** B

**Question 2:** Which behavior is unsafe?

A. Reporting a blocked legitimate business need  
B. Using approved remote access  
C. Disabling endpoint protection to install a tool  
D. Locking your screen when stepping away

**Correct answer:** C

**Question 3:** Why should administrator rights be limited?

A. Admin rights can allow major system changes and increase damage if misused or compromised  
B. Admin rights make keyboards slower  
C. Admin rights prevent all cyberattacks  
D. Admin rights are only for email

**Correct answer:** A

**Question 4:** What should leadership verify?

A. Whether protective controls are defined, enforced, monitored, and reviewed  
B. Whether employees can bypass controls easily  
C. Whether all users have admin rights  
D. Whether logs are deleted quickly

**Correct answer:** A
