### Use the Minimum Necessary Data


### Practical Exercise

For each situation, decide whether the data use is appropriate or excessive.

#### Situation 1

A vendor needs to confirm delivery quantities. The employee sends only product codes, quantities, and delivery regions.

Expected answer:

Appropriate.

#### Situation 2

A team member sends an entire customer export to answer a question about one customer.

Expected answer:

Excessive.

#### Situation 3

A manager shares a view-only report with only the people who need it.

Expected answer:

Appropriate.

#### Situation 4

An employee uses real customer data in a training demo when fake data would work.

Expected answer:

Excessive.

#### Situation 5

An employee removes names and account numbers before asking an approved AI tool to summarize a generic issue.

Expected answer:

Appropriate, assuming company policy allows that use.

#### Situation 6

A team keeps old sensitive exports in a shared folder because they may be useful someday.

Expected answer:

Excessive.


### Short Knowledge Check

**Question 1:** What does “minimum necessary data” mean?

A. Use as much data as possible for better context  
B. Use only the data needed to complete the task  
C. Never use data for business purposes  
D. Send full files to avoid missing anything

**Correct answer:** B

**Question 2:** What should you do before sending a spreadsheet externally?

A. Send the full file so the recipient can decide what matters  
B. Check for unnecessary rows, columns, tabs, comments, and sensitive fields  
C. Rename the file only  
D. Convert it to PDF without reviewing it

**Correct answer:** B

**Question 3:** Why is using less sensitive data safer?

A. It reduces the damage if information is exposed  
B. It makes files look smaller  
C. It removes the need for access control  
D. It prevents all cyberattacks

**Correct answer:** A

**Question 4:** What should employees do before pasting company information into an AI tool?

A. Paste the full file for better results  
B. Check whether the tool is approved and remove unnecessary sensitive data  
C. Use personal accounts to avoid company controls  
D. Include names and account numbers for accuracy

**Correct answer:** B

**Question 5:** What should leadership verify?

A. Whether the company is reducing unnecessary collection, sharing, copying, and retention of sensitive data  
B. Whether employees send all available information  
C. Whether old exports are kept forever  
D. Whether vendors can access full datasets by default

**Correct answer:** A

### Share Data Safely



### Practical Exercise

Classify each behavior as safe or unsafe.

#### Behavior 1

Sharing a confidential file with named users only, using view-only access and an expiration date.

Expected answer:

Safe.

#### Behavior 2

Sending a full customer spreadsheet to a vendor when the vendor only needs order totals.

Expected answer:

Unsafe.

#### Behavior 3

Using “anyone with the link” for a folder containing internal pricing.

Expected answer:

Unsafe.

#### Behavior 4

Starting a new email instead of forwarding a long thread with sensitive history.

Expected answer:

Safe.

#### Behavior 5

Uploading a legal contract to an unapproved AI tool for summarization.

Expected answer:

Unsafe.

#### Behavior 6

Reporting immediately after sending a sensitive file to the wrong person.

Expected answer:

Safe.


### Short Knowledge Check

**Question 1:** What should you check before sharing sensitive information?

A. Recipient, purpose, sensitivity, permission level, and sharing method  
B. File color and file name only  
C. Whether the message sounds polite  
D. Whether the recipient asked urgently

**Correct answer:** A

**Question 2:** What is the safest default for cloud sharing?

A. Anyone with the link  
B. Public access  
C. Named users with the lowest necessary permission  
D. Full edit access for convenience

**Correct answer:** C

**Question 3:** Why can forwarding email threads be risky?

A. They may contain old sensitive information below the latest message  
B. They always fail to send  
C. They remove all attachments automatically  
D. They cannot be read by external users

**Correct answer:** A

**Question 4:** What should you do if you send sensitive data to the wrong person?

A. Delete your copy and say nothing  
B. Report it immediately through the approved process  
C. Wait to see if anyone notices  
D. Ask the recipient to ignore it and move on

**Correct answer:** B

**Question 5:** What should leadership verify?

A. Whether employees can share any data using any tool  
B. Whether the company has approved sharing methods, controls, monitoring, and reporting procedures  
C. Whether all files are public by default  
D. Whether external users keep access permanently

**Correct answer:** B

### Use Approved Tools and AI Services


### Practical Exercise

Classify each behavior as safe or unsafe.

#### Behavior 1

Using the company-approved AI tool to summarize a non-sensitive internal announcement, then reviewing the output before sending.

Expected answer:

Safe.

#### Behavior 2

Uploading a confidential contract to a free online document converter.

Expected answer:

Unsafe.

#### Behavior 3

Checking the approved application list before using a new productivity tool.

Expected answer:

Safe.

Installing a browser extension that asks to read all website data without approval.

Expected answer:

Unsafe.

#### Behavior 5

Using a personal cloud account to store customer files for convenience.

Expected answer:

Unsafe.

#### Behavior 6

Removing customer names and account numbers before using an approved AI tool to draft a generic response.

Expected answer:

Safe, if company policy allows that use.

### Short Knowledge Check

**Question 1:** What should you check before using a tool with company data?

A. Whether the tool is popular  
B. Whether the tool is approved for that type of data and task  
C. Whether the tool has a nice interface  
D. Whether coworkers have heard of it

**Correct answer:** B

**Question 2:** Why are unapproved AI tools risky?

A. They are always slow  
B. They may process, retain, or expose company information outside approved controls  
C. They cannot generate text  
D. They only work for technical users

**Correct answer:** B

**Question 3:** What should you avoid entering into unapproved AI tools?

A. Customer data  
B. Passwords or API keys  
C. Confidential business information  
D. All of the above

**Correct answer:** D

**Question 4:** What should you do if a browser extension asks for broad access to company web pages?

A. Approve it if it looks useful  
B. Install it only on weekends  
C. Stop and check whether it is approved  
D. Share the extension with your team

**Correct answer:** C

**Question 5:** What should leadership verify?

A. Whether employees can use any tool they want  
B. Whether the company has an inventory, approval process, AI rules, and vendor review for tools handling company data  
C. Whether personal accounts are easier to use  
D. Whether public AI tools are faster

**Correct answer:** B

### Establish Data Governance and Mitigate Risk


### Practical Exercise

Classify each situation as strong or weak data governance.

#### Situation 1

Each major data set has an owner, approved storage location, access rules, and retention period.

Expected answer:

Strong.

#### Situation 2

Employees use different AI tools with customer and HR data because there is no approved AI policy.

Expected answer:

Weak.

#### Situation 3

External users in cloud folders are reviewed quarterly and removed when no longer needed.

Expected answer:

Strong.

#### Situation 4

Old sensitive exports are kept forever in shared folders with broad access.

Expected answer:

Weak.

#### Situation 5

The company has a simple classification model with practical examples for staff.

Expected answer:

Strong.

#### Situation 6

Vendor data sharing happens informally by email without approval or records.

Expected answer:

Weak.

### Short Knowledge Check

**Question 1:** What is data governance?

A. A rule that all data must be deleted immediately  
B. A system of ownership, rules, and controls for handling company data  
C. A technical task only for IT  
D. A way to make data sharing impossible

**Correct answer:** B

**Question 2:** Why should sensitive data have an owner?

A. So someone is accountable for access, storage, sharing, retention, and protection  
B. So only executives can use it  
C. So it can be copied freely  
D. So employees do not need training

**Correct answer:** A

**Question 3:** Which is a warning sign of weak data governance?

A. Approved storage locations  
B. Named data owners  
C. Public links to sensitive folders  
D. Periodic access reviews

**Correct answer:** C

**Question 4:** What should leadership verify about AI tools?

A. Whether employees like using them  
B. Whether approved AI tools, allowed use cases, and data restrictions are defined  
C. Whether all AI output is automatically correct  
D. Whether public AI tools can replace company systems

**Correct answer:** B

**Question 5:** What is the strongest leadership standard?

A. “We have a policy somewhere.”  
B. “Employees are probably careful.”  
C. “Show evidence that sensitive data is identified, owned, controlled, and protected.”  
D. “Everyone can decide their own tools.”

**Correct answer:** C
