## Open Source and Affordable Cybersecurity Support Tools

This compendium lists open source, free, low-cost, commonly bundled, or affordable tools that can help SMEs organize, implement, monitor, and evidence the cybersecurity practices covered in this course.

This is not an endorsement list. Each organization should review current pricing, licensing, hosting model, data handling, support, and security requirements before adopting any tool.

<br>






This appendix lists open source, free, commonly bundled, low-cost, or affordable tools that may help SMEs organize, implement, monitor, and evidence the cybersecurity practices covered in this course.

We don't necessarily endorse all of these for every use case, but think they are worth considering. Each organization should review current pricing, licensing, hosting model, data handling, security features, support, and internal capability before adopting any tool.

## How to Use

|Question|What to Look For|
|---|---|
|What task are we trying to manage?|Asset inventory, password management, vulnerability scanning, backups, incident reporting, training, vendor oversight, etc.|
|What tool could help?|A tool that supports the task without creating excessive administrative burden.|
|What evidence can it produce?|Reports, exports, dashboards, logs, tickets, test results, or review records.|
|Who owns the process?|A named person or provider responsible for using the tool and reviewing the outputs.|

## Suggested Minimum Evidence Pack for Leadership

|Evidence Area|What Leadership Should Request|
|---|---|
|Assets|Current device inventory and software inventory|
|Identity|MFA coverage report, admin account review, access review records|
|Passwords|Password manager adoption report|
|Devices|Endpoint protection coverage, encryption status, device compliance|
|Patching|Patch compliance report and overdue update list|
|Vulnerabilities|Critical vulnerability report and remediation status|
|Backups|Backup success/failure report and restore test evidence|
|Incidents|Incident and near-miss register|
|Phishing|Phishing report metrics and simulation results, if used|
|Data Protection|External sharing review, data exposure reports, DLP alerts if available|
|Vendors|Vendor/MSP responsibility matrix and provider security reports|
|Governance|Risk register, exception register, tabletop exercise results|
|Improvement|Security action tracker with owners, due dates, and completion evidence|

A tool is useful only if it helps the company answer:

**What do we own, what is protected, what is exposed, what failed, who owns the fix, and what evidence proves improvement?**
