
### Minimum Executive Cyber Operating Model

**At minimum, SMEs should have:**

1. Named executive owner
    
2. Named IT/security owner
    
3. Current asset and software inventory
    
4. Approved tool list
    
5. MFA coverage review
    
6. Backup and restore evidence
    
7. Vulnerability remediation tracking
    
8. Incident reporting process
    
9. Incident response plan and tabletop exercise
    
10. Vendor/MSP responsibility matrix
    
11. Access review process
    
12. Exception register
    
13. Security awareness training
    
14. Quarterly cybersecurity review
    
15. Improvement action tracker
    

This is not about bureaucracy. It is about making sure critical security work does not depend on memory, assumptions, or goodwill.



### Short Scenario

During a quarterly review, leadership asks whether the company is prepared for ransomware. The MSP says backups are running, endpoint protection is installed, and users have MFA. No one can provide the latest restore test result, endpoint coverage report, MFA exception list, critical vulnerability status, or incident response exercise results.

Ask learners:

1. What is missing from the assurance process?
    
2. Why are verbal assurances not enough?
    
3. What evidence should leadership request?
    
4. What actions should be tracked?
    
5. Who should own follow-up?
    

Expected answer:

The company is relying on assumptions instead of evidence. Leadership should request restore test results, endpoint coverage, MFA coverage and exceptions, vulnerability status, incident response exercise results, and MSP responsibility evidence. Any gaps should be assigned to named owners with due dates and reviewed until closed.

### Short Knowledge Check

**Question 1:** What does it mean to make cybersecurity operational?

A. Buy tools and assume they work  
B. Assign ownership, review evidence, track risks, manage exceptions, and improve controls  
C. Let each employee decide their own process  
D. Review cybersecurity only after an incident

**Correct answer:** B

**Question 2:** What should executives request from IT or providers?

A. Verbal reassurance only  
B. Evidence that key controls are deployed, monitored, tested, and improving  
C. No information unless there is a breach  
D. Only invoices

**Correct answer:** B

**Question 3:** Why should exceptions be tracked?

A. Because exceptions are always forbidden  
B. Because untracked exceptions can become permanent unmanaged risk  
C. Because employees should manage all exceptions themselves  
D. Because exceptions eliminate risk

**Correct answer:** B

**Question 4:** What is a key manager responsibility?

A. Encourage staff to bypass controls when busy  
B. Reinforce secure behavior and escalate issues quickly  
C. Hide incidents from leadership  
D. Approve all software personally without review

**Correct answer:** B

**Question 5:** What is the strongest executive question?

A. Can we assume this is handled?  
B. What are we assuming that we have not verified?  
C. Can we delay this forever?  
D. Can IT explain this without evidence?

**Correct answer:** B
